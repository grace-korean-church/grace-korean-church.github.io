# Grace Korean Church design system

The page layout, routes, content, photos, navigation and video behavior are preserved.
The style is warm and comfortable: ivory surfaces, the existing navy accent (#1f4e79),
native sans-serif Korean headings, serif English headings and readable sans-serif body text. Use the shared tokens in
`assets/css/tokens.css`; dark mode uses warm slate surfaces. The container stays
1040px with the existing mobile breakpoints and section sequence. Controls use a
quiet 6px radius, visible keyboard focus, and reduced-motion support. Do not add
photographs, facts or promotional claims without supplied material.
